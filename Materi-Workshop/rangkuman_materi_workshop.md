
# Rangkuman Materi Workshop
## Building with AI, Managing Change with GitHub

### 1. Prompt Engineering
Teknik menyusun instruksi kepada AI agar menghasilkan jawaban yang tepat dan sesuai kebutuhan. Struktur prompt yang baik terdiri dari Role, Task, Context, dan Format. Konteks dan instruksi yang jelas dapat meningkatkan kualitas hasil AI.

### 2. Git dan GitHub
- **Git:** Version Control System untuk melacak dan mengelola perubahan file.
- **GitHub:** Platform online untuk menyimpan repository Git dan mendukung kolaborasi.

### 3. Git Workflow
Git memiliki tiga bagian utama:
- **Working Directory:** Tempat mengedit file.
- **Staging Area:** Tempat menyiapkan perubahan sebelum commit.
- **Git Directory:** Tempat menyimpan data dan riwayat repository.

### 4. Perintah Dasar Git
- `git init` – Membuat repository Git.
- `git add .` – Memasukkan perubahan ke staging area.
- `git commit -m "pesan"` – Menyimpan perubahan.
- `git push origin main` – Mengirim perubahan ke GitHub.
- `git pull origin main` – Mengambil perubahan dari GitHub.
- `git clone URL` – Menyalin repository ke komputer.

### 5. Konfigurasi Git dan SSH
Git memerlukan konfigurasi nama dan email pengguna. Selain itu, SSH Key dapat digunakan untuk autentikasi saat menghubungkan komputer dengan GitHub.

### 6. Praktik Student Task Planner
Workshop memperkenalkan pembuatan aplikasi pengelola tugas mahasiswa menggunakan bantuan AI. Prosesnya meliputi penyusunan prompt, pembuatan aplikasi, inisialisasi Git, commit, push, serta pengelolaan perubahan proyek.

### Kesimpulan
AI membantu proses pengembangan aplikasi melalui instruksi yang tepat, sedangkan Git dan GitHub membantu mengelola perubahan serta menyimpan proyek secara terstruktur.
