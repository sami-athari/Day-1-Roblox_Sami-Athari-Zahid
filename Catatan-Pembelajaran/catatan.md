
# Catatan Pembelajaran
## Building with AI, Managing Change with GitHub

### Hal Penting yang Dipelajari

1. Prompt yang spesifik dan memiliki konteks akan membantu AI menghasilkan jawaban yang lebih sesuai.
2. Struktur prompt terdiri dari Role, Task, Context, dan Format.
3. Git digunakan untuk mengelola perubahan file, sedangkan GitHub digunakan untuk menyimpan repository secara online.
4. Git memiliki tiga tahapan utama, yaitu Working Directory, Staging Area, dan Git Directory.
5. Add digunakan untuk menyiapkan perubahan, Commit untuk menyimpan perubahan, dan Push untuk mengirimkannya ke GitHub.
6. SSH Key dapat digunakan untuk menghubungkan komputer dengan GitHub secara aman.
7. AI dapat membantu pembuatan aplikasi, sedangkan Git dan GitHub membantu mengelola perkembangan proyek.

### Pengetahuan Baru

Melalui workshop ini, saya memahami bahwa AI tidak hanya digunakan untuk mencari informasi, tetapi juga dapat membantu proses pembuatan aplikasi. Saya juga mempelajari pentingnya Git dan GitHub dalam menyimpan serta mengelola perubahan proyek.

### Kesimpulan Pembelajaran

Prompt Engineering, Git, dan GitHub merupakan keterampilan yang saling mendukung dalam pengembangan proyek digital. Penggunaan AI yang tepat serta pengelolaan proyek yang terstruktur dapat membantu proses pengerjaan menjadi lebih efektif.
